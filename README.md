# Customer Segmentation & Sales Performance Dashboard

A comprehensive data analytics project built in **Power BI** to evaluate e-commerce transaction cycles, analyze regional sales distributions, and segment customers using RFM-style patterns. This dashboard converts raw operational data into interactive, actionable business insights for sales strategy optimization.

## 💡 Key Business Insights Discovered

Based on the visualized metrics in the dataset (£17.37M Total Sales across 5.87K Customers and 36.97K Orders):

* **High-Value Concentration:** The **"Champions"** customer segment is the primary engine of growth, generating a massive **68.6% of total revenue** despite accounting for a much smaller percentage of the overall customer count.
* **Regional Dominance:** The **United Kingdom** stands out as the single largest market by a vast margin, driving the overwhelming majority of global sales volume.
* **Churn Vulnerability:** The **"Hibernating / Lost"** segment represents a critical retention risk, holding **27.88% of the total customer base** but contributing only 4.2% to overall revenue. 
* **Operational Benchmarks:** The average order size maintains a stable health baseline with an **Average Order Value (AOV) of £469.98**.

## 🛠️ Tech Stack & Skills Demonstrated

* **Data Modeling:** Star schema architecture connecting transaction tables, regional maps, and customer profile dimensions.
* **Power Query (M Language):** Extracted, transformed, and cleaned the raw database rows to build normalized customer categories.
* **DAX (Data Analysis Expressions):** Engineered custom metrics including rolling multi-year sales totals, average order sizes, and categorical percentage splits.
* **Data Visualization:** Built unified layout systems with consistent visual grouping, color hierarchy, and responsive tooltips for intuitive drill-downs.
